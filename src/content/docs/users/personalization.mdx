## Theme

Fancy Mumble ships with eleven themes. Click a swatch card to apply
it instantly.

- **Mobel**
- **Rose**

## Bubble style (chat messages)

Three looks for individual chat messages:

- **Bubbles** (default): rounded chat bubbles, like a messenger app.
- **Flat**: clean rows, like a classic forum.
- **Compact**: dense, several lines fit per visible row.

## Chat background

Drop an image or pick a color to set the background of the chat
column.

- **Fit**: pick **Cover** (fills, may crop) or **Tile** (repeats).
- **Dim**: darken the image so text stays readable. 0 to 100%.
- **Blur**: blur the image. The blur is calculated in the backend,
  so very large values may take a moment to re-process.

<Aside type="tip">
The original image is stored locally and re-processed when you
change blur or dim, so you can iterate without re-uploading.
</Aside>

## Font

Pick from a curated list of fonts. The default is your system font.

## Font size

Three sizes: small, **medium** (default), large.

## Compact mode

A toggle that hides avatars and tightens the chat spacing for a
denser layout.

## Resetting

The **Danger Zone** at the bottom of **Settings, Advanced** has a
**Reset** button that restores everything to defaults.

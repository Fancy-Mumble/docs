A one-page cheat sheet. All keys in the **Configurable** section can
be re-bound under **Settings, Shortcuts**.

<Aside type="note">
For how to bind keys, see the
[Keyboard shortcuts](/users/shortcuts/) page in the For Users section.
</Aside>

## Configurable (Settings, Shortcuts)

### Voice (global)

| Action | Default |
|--------|---------|
| Push to talk | unbound |
| Toggle mute | `Ctrl+Shift+M` |
| Toggle deafen | `Ctrl+Shift+D` |
| Voice priority (hold to override) | unbound |

### Voice (in-app)

| Action | Default |
|--------|---------|
| Toggle activation mode | unbound |

### Channel and navigation

| Action | Default |
|--------|---------|
| Move to channel above | `Alt+ArrowUp` |
| Move to channel below | `Alt+ArrowDown` |
| Jump to root channel | `Alt+Home` |
| Toggle channel sidebar | `Ctrl+B` |
| Toggle member panel | `Ctrl+U` |
| Open Quick Switcher | `Ctrl+K` |

### Window

| Action | Default |
|--------|---------|
| Open Settings | `Ctrl+,` |
| Toggle fullscreen | `F11` |
| Toggle developer overlay (Expert only) | `Ctrl+Shift+I` |

## Built-in chat composer (not configurable)

| Action | Key |
|--------|-----|
| Focus composer | `Tab` |
| Send message | `Enter` |
| New line | `Shift+Enter` |
| Edit last message (in empty composer) | `ArrowUp` |
| Bold | `Ctrl+B` |
| Italic | `Ctrl+I` |
| Inline code | `Ctrl+E` |
| Emoji picker | type `:` then search |
| Mention picker | type `@` then search |

## Mobile gestures

There are no keyboard shortcuts on Android. Touch alternatives:

| Gesture | Action |
|---------|--------|
| Swipe in from the edge | Open channel drawer or member sheet |
| Long-press on message | Open action sheet |
| Pull down on chat | Refresh |

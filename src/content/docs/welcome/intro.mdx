title: What is Fancy Mumble?
description: The client, Starling server, compatibility, and feature availability.

Fancy Mumble is a voice chat app for Windows, Linux, and Android. It uses the Mumble protocol for voice and control, with chat, profiles, screen sharing, and other features in the client.

The current server is [Starling](https://github.com/Fancy-Mumble/starling), a Rust implementation with a gateway and separate services for voice, chat, files, and more. For an existing deployment, see [Migrating to Starling](/server/migrating-to-starling/).

The client can connect to a standard Mumble server for voice and basic text chat. Fancy features depend on what the server advertises and on its configuration. Some also need a plugin or a reachable media service. See [Feature availability](/server/features/) before planning a deployment around a particular feature.

The guides and screenshots show the current client interface.

## Start here

- [Install the app](/getting-started/install/) and [connect to a server](/getting-started/connect/).
- [Run Starling with Docker](/server/docker/) or use a [release package](https://github.com/Fancy-Mumble/starling/releases/latest).
- [Configure Starling](/server/config/) and check [ports](/server/network/).

Fancy Mumble is independent of the official [Mumble project](https://www.mumble.info/). Mumble names here refer to protocol compatibility.

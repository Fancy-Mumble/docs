Fancy Mumble is a **voice chat program** for gaming, podcasts, study
groups, and online communities. You install the app, connect to a
server, and talk. Chat, screen sharing, file sharing, and much more is
built in.

It is based on Mumble, an open-source voice chat program that has been
around for over a decade, so the call quality and reliability are
already excellent. Fancy Mumble adds a modern look, a smoother first-run
experience, and a handful of features you would expect from a 2026 app.

<Aside type="tip" title="Compatible with classic Mumble">
The Fancy Mumble app can connect to any standard Mumble server. You
just will not see the extra features (saved chat history, smooth screen
sharing, file uploads, custom server emotes, push notifications) unless
the server runs Fancy Mumble too.
</Aside>

## What is new compared to classic Mumble

<Badge text="Highlights" variant="success" />

- **Crystal-clear voice with AI noise removal.** Pick the algorithm
  that fits your machine and your room.
- **Chat that survives disconnects.** Open the app the next day and
  the conversation is still there (encrypted on the server).
- **Smooth screen sharing.** One person streams, the server fans it
  out to everyone, no peer-to-peer headaches.
- **A whiteboard on top of any stream.** Point, draw, annotate.
- **Watch a video together** in sync.
- **Reactions and polls** on chat messages.
- **Custom server emotes.** Admins can upload images and use them as
  emoji.
- **File sharing** with control over who can download, for how long.
- **Server-rendered link previews** so links look like links.
- **Push notifications** on Android.
- **Join-time onboarding** so new members are dropped into the right
  channels with the right roles.
- **Profile customization** including avatars, banners, name styles,
  glow effects, and animated frames.

You do not need to memorize this, but if you ever need to ask your
network admin to open a port, this is what the traffic looks like:

  component "Voice + Control\\nTCP/UDP 64738" as Voice
  component "WebRTC SFU\\nscreen-share relay\\nUDP 10000" as SFU
  component "File Server\\nHTTP 64739" as FS
  component "Push Relay\\n→ Firebase" as Push

App --> Voice : TCP/UDP 64738  direct

<Aside type="caution" title="Ports recap">
Default ports: **64738** for voice and control, **64739** for the
file server, **10000** for screen sharing. Full reference on the
[Ports & protocols](/reference/ports/) page.
</Aside>

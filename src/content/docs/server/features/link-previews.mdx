---
title: Link previews
description: Bounded server-side previews for links shared in chat.
---

Starling's **link-preview** service fetches page metadata and preview pictures for URLs shared in chat. The resulting card is sent to clients, so members receive the same preview and do not each fetch its image from the origin.

## Configure preview fetching

The service is part of the default stack. Its options live under `[services.link-preview.options]`. Values in this options table are strings.

~~~toml
[services.link-preview.options]
preview_timeout_ms = "5000"
preview_max_bytes = "1048576"
preview_redirects = "3"
preview_concurrency = "8"
preview_image_max_bytes = "2097152"
preview_image_edge = "640"
~~~

These limits bound page fetches, redirects, parallel work, and thumbnail size. Setting `preview_image_max_bytes = "0"` disables preview pictures. Read the [Starling configuration reference](https://github.com/Fancy-Mumble/starling/blob/main/examples/reference.toml) before changing the limits.

## Privacy and troubleshooting

The destination site sees a request from your server. Outbound DNS, firewall, and proxy rules can prevent a preview from loading. Check the link-preview service logs, then test a public page with Open Graph metadata. A page without suitable metadata may produce only a text link.

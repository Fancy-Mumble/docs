---
title: First-run setup
description: Start Starling and find its generated administrator credentials.
---

Starling starts with working defaults. On its first run it writes a starter config, creates the server certificate and SuperUser account, and prints the generated password. Save that password and keep the data directory or Docker volume.

For a local binary, run Starling in all-in-one mode and connect to localhost:64738. For Docker, follow [Run Starling with Docker](/server/docker/). Then adjust starling.toml using [Configuration](/server/config/).

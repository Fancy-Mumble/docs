## How the pieces fit together

Fancy Mumble has three parts that work as one:

| Part | What it does |
|------|--------------|
| **The app** | The program you install on your computer or phone to talk and chat. |
| **The server** | A program someone runs (maybe you) that everyone connects to. |
| **The Docker image** | A pre-packaged server with an interactive setup wizard for fast deployment. |
